1. Make the six Blackpine problem families the public entry layer.

5. Provide safe alternate contact fields for possible compromise.
6. Keep sensitive incident text out of site-managed browser storage.
7. Improve search/404 routing around ordinary customer language.
8. Add quiet accessibility improvements without changing the established visual language.
9. Keep R&D-only capabilities non-public.
10. Keep Phase 1 operational-claim gates intact.
