# Image Phase 1 audit

Status: implemented on `phase-1-visual-refinement`.

## Decisions

- Keep the homepage hero graphic/typographic; do not convert it to a stock-photo hero.
- Use one visual beat before the problem-routing section and one Labs image band later on the homepage.
- Use a distinct infrastructure image on Home so Company keeps its own architecture/Canada visual language.
- Keep Services to one infrastructure anchor between problem-first routing and specialist services.
- Keep individual service pages photography-light so scope, evidence, methods, and boundaries remain primary.
- Keep Research featured images square at all breakpoints.
- Keep Trust documentation-first and image-light.
- Treat non-informational photography as decorative in accessibility output.
- Add explicit Company captions so architecture and Toronto imagery cannot be mistaken for Blackpine premises.
- Lazy-load all below-hero editorial photography and keep it low fetch priority.
- Preserve deliberate focal points with asset-specific `object-position`.
- Respect reduced-motion preferences on research-card image motion.

## Visual rhythm

Photography is used as a structural pause, not as decoration beside every heading. The current production set intentionally remains sparse.
