# Image Phase 2 — page-specific art direction

Status: implemented on `phase-2-page-art-direction`.

## Reusable treatments

1. **Graphic hero** — Home keeps the Blackpine system-map hero; photography does not replace brand identity.
2. **Wide structural beat** — Home and Capabilities use one wide image to change page rhythm between information systems.
3. **Asymmetric duo** — Company uses architecture plus Canadian context with explicit captions.
4. **Square editorial cards** — Research uses 1:1 technical imagery for selected publications.
5. **Full-width project band** — Labs uses a hardware macro behind project-specific copy.
6. **Editorial split** — Careers and Contact use a single image paired with page-specific context, not a repeated generic template.

## Intentional exceptions

- Trust remains documentation-first and does not receive decorative photography.
- Individual service-detail pages remain primarily technical and text-led.
- Cipher detail pages do not use generic hardware imagery that could imply implementation facts not established by the project documentation.

## Representation rules

- Human editorial photography must not imply the subjects are Blackpine staff.
- Canadian city imagery must not imply a pictured building or location is a Blackpine office.
- Decorative/contextual images use empty alt text; nearby visible copy carries the actual meaning.
- Photography stays sparse enough that each image has a clear structural role.
