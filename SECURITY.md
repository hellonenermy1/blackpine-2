# Security Policy

Please do not publish suspected vulnerabilities in a public GitHub issue.

Report security issues privately to **security@blackpinecybersecurity.com** and include the affected component or hostname, a concise description, and reproduction information that does not expose unrelated data.

Do not use a vulnerability report as authorization to access unrelated systems, customer data, third-party services, or accounts. Avoid denial-of-service testing, social engineering, destructive testing, and unnecessary access to data.

The public disclosure policy is also available at:

https://blackpinecybersecurity.com/trust/responsible-disclosure/
