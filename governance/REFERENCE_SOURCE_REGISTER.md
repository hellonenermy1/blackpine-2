# Reference Source Register

Last verified: 2026-10-24

This register tracks authoritative sources that Blackpine names in public methodology or evidence material. Framework names are references, not certification claims.

| Reference | Current version checked | Authoritative source | Blackpine use |
|---|---|---|---|
| NIST Cybersecurity Framework | 2.0 | https://csrc.nist.gov/pubs/cswp/29/the-nist-cybersecurity-framework-csf-20/final | Cybersecurity risk governance, outcomes, profiles and risk-management context. |
| CIS Critical Security Controls | v8.1 | https://www.cisecurity.org/controls | Prioritized safeguards and practical control context. |
| OWASP Top 10 | 2025 | https://owasp.org/projects/top-ten | Web-application risk awareness and common risk categories. |
| OWASP Application Security Verification Standard | 5.0.0 | https://asvs.owasp.org/ | Web-application verification requirements and testing structure. |
| MITRE ATT&CK | v20.0 | https://attack.mitre.org/resources/versions/ | Adversary behaviour, technique context and detection-oriented analysis. |

## Review rules

1. Verify version changes against the authoritative publisher, not a secondary article or search snippet.
2. Record the review date when a version is changed.
3. Review material methodology mappings before adopting a new major version.
4. Preserve engagement-specific version references in delivered reports when reproducibility requires them.
5. Do not describe framework use, mapping or alignment as certification.
6. If a source is superseded, update the register and affected public material together.
