# External Reputation Evidence Register

## Purpose

Track third-party credibility records before they are used in Blackpine marketing or Trust content.

## Status values

- OPEN — desired evidence does not yet have a verified public record.
- VERIFIED — the public record has been checked and may be referenced subject to any logo/badge rules.
- STALE — a previously verified record needs re-checking or no longer reflects the current state.
- RETIRED — the claim should no longer be published.

## Register

| Evidence type | Status | Minimum verification before publication |
|---|---|---|
| Google Business reviews/rating | OPEN | Confirm official profile URL, current rating/count, and review-platform display rules. |
| Clutch profile/reviews | OPEN | Confirm official company profile and current review record. |
| Other business directories | OPEN | Confirm listing ownership/identity and current record. |
| Vendor partnership | OPEN | Confirm active partner relationship and permission to use partner mark/logo. |
| Customer logo | OPEN | Confirm client identity and written publication right for the logo. |
| ISO certification | OPEN | Confirm valid certificate, scope, certification body, dates, and public-verification method. |
| SOC 2 report | OPEN | Confirm completed independent report and distribution rules; do not post restricted report material publicly. |
| CVE attribution | OPEN | Confirm assigned CVE and external record naming Blackpine or the relevant researcher. |
| Vendor acknowledgement / hall of fame | OPEN | Confirm external vendor page or official acknowledgement. |
| Conference / podcast / media appearance | OPEN | Confirm organizer/publisher record and participant identity. |
| External publication/byline | OPEN | Confirm publisher page and author attribution. |

## Rules

1. A planned profile is not a verified profile.
2. A review request is not a positive review.
3. Use of a vendor product is not a partnership.
4. A certification-readiness project is not certification.
5. A vulnerability report is not a CVE until an identifier is actually assigned.
6. Blackpine-owned pages cannot independently verify Blackpine-owned claims.
7. Record the external URL, verification date, owner, and any expiry/review date before moving an item to VERIFIED.
8. Re-check time-sensitive evidence before prominent publication.

No item in this register is promoted to VERIFIED solely because this file exists.
