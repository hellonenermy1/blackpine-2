# External Reputation Evidence Register

## Purpose

Track third-party credibility records before they are used in Blackpine marketing or Trust content.

## Status values

- OPEN — desired evidence does not yet have a verified public record.
- VERIFIED — the public record has been checked and may be referenced subject to any logo/badge rules.
- STALE — a previously verified record needs re-checking or no longer reflects the current state.
- RETIRED — the claim should no longer be published.

## Rules

1. A planned profile is not a verified profile.
2. A review request is not a positive review.
3. Use of a vendor product is not a partnership.
4. A certification-readiness project is not certification.
5. A vulnerability report is not a CVE until an identifier is actually assigned.
6. Blackpine-owned pages cannot independently verify Blackpine-owned claims.
7. Record the external source, verification date, owner, and any expiry/review date before moving an item to VERIFIED.
8. Re-check time-sensitive evidence before prominent publication.
9. Verification of a business profile can support stable business identity/address/phone facts when Blackpine has approved those details for public use; it does not freeze dynamic rating, review-count or hours data.
10. Never create a LinkedIn, Clutch, directory, partnership, media, or technical-recognition claim from a search result that does not clearly identify Blackpine.

No item in this register is promoted to VERIFIED solely because this file exists.
