# Blackpine production image shortlist — 30

Status: curated production shortlist only. **Do not reference these files from the website yet.** The original 50-image library remains intact.

## Art direction

The selected set is intended to feel documented, technical, restrained, and institutional rather than like generic cybersecurity stock photography.

Rules for later use:
- avoid hoodie-hacker, glowing-lock, Matrix-code, and staged-boardroom imagery;
- favour real infrastructure, physical systems, architecture, hardware, and naturally observed work;
- use human images sparingly and never imply photographed people are Blackpine staff unless that is actually true;
- keep colour treatment restrained: deep neutrals, steel, concrete, cool practical light, with occasional red/green hardware accents;
- crop intentionally rather than forcing every source into the same ratio.

## Format balance

- Landscape target: **12**
- Portrait target: **9**
- Square / 1:1 target: **9**
- Total: **30**

The crop label below is the preferred website treatment, not a claim about the source file's native aspect ratio.
